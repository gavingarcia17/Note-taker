# Note Taker

## Description

Note Taker is a web application that allows users to organize their thoughts and ideas by creating, saving, and deleting notes. The application uses local storage to persist notes between sessions.

## Features

- Create new notes with a title and content.
- Save notes to local storage.
- View a list of saved notes.
- Delete notes from the saved list.
- Search notes by title.
- Toggle between light and dark themes.

## Installation

1. Clone the repository to your local machine:
    ```sh
    git clone https://github.com/your-username/note-taker.git
    ```

2. Navigate to the project directory:
    ```sh
    cd note-taker
    ```

3. Install the dependencies:
    ```sh
    npm install
    ```

4. Create a `.env` file in the root directory and add the following:
    ```env
    PORT=4000
    ```

5. Start the server:
    ```sh
    npm start
    ```

6. Open your browser and navigate to `http://localhost:4000`.

## Usage

1. Open the application in your browser.
2. Click the "Start Taking Notes" button to navigate to the notes page.
3. Enter a title and content for your note.
4. Click the save button to save the note.
5. View your saved notes in the list on the left.
6. Click on a note in the list to view its content.
7. Click the delete button next to a saved note to remove it.
